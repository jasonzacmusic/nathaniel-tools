Caught Three failures that would have hit you before they hit anyone else

What I foundHow it would have shown up
ReaImGui renamed two constants the apps use (Col_TabActive, ChildFlags_Border)Palette & Look, Track Settings Transfer and Stem Print would all have crashed the moment you opened them on a current ReaImGui. Fixed with one shared compatibility file so future renames are a one-line change.

StageRig's builder muted only the patch folder, not the tracks inside itThe first patch change of a set would have behaved differently from every one after it. Caught by the build test, fixed.

Built StageRig v0 — your Lagori rig, in REAPER

Three new pieces, all working: an importer that reads your concert and writes a rig spec, a note-tracker effect that makes mid-phrase patch changes survivable, and the StageRig stage view with the switch sequence and panic buttons.

The switch does what MainStage does, in the order that matters: unmute the incoming patch first, stop new notes reaching the outgoing one, let it ring for a couple of seconds, then flush its held notes and sustain and mute it. Note handling lives in the audio engine, not in scripting — scripting is far too slow and jittery to touch notes.

Caught late The ReaPack install would have delivered broken scripts

I told you earlier that installing works because I verified subscribing to the repository works. That was not the same claim, and the difference mattered: six scripts load shared library files, but ReaPack gives each package exclusive ownership of the files it installs, so they could not each carry a copy. Installing any one app would have succeeded and then failed the moment you ran it, with an error that looks like a broken script rather than a packaging mistake.

Fixed: the libraries now live in their own NPH Shared Libraries package, every app that needs it says so, and the index generator refuses to build if one ever forgets again. Then I checked it properly — all 24 files download from the live index with matching checksums, and all 14 layout checks pass inside REAPER. The easiest install is to right-click the repository in ReaPack and choose Install All.

What still stands between this and a real gig

  1. The sounds themselves. Every track loads its plugin, but with a default patch. Someone has to sit down and choose the actual Omnisphere / Kontakt / BBC SO presets for eighteen tracks. That is your ear, not my code — and it is exactly the part you said you would fill in later.
  2. An organ. Ten of your patches are B3 parts. Authorising the Arturia V Collection so Analog Lab V loads would fix it in one step.
  3. Key zones and transpose. Splits, velocity layers and the G→A transpose on Humma Humma are in the concert file but not yet carried across.
  4. Hands-free switching. Right now you change patch by clicking. A footswitch or program-change binding is next.
  5. Loop Deck — the Ableton-style loop triggering — is specced, not built.
  6. Rehearsal. Then a low-stakes gig. Then, and only then, do we call it a MainStage replacement.
