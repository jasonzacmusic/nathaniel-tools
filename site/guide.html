How to actually use it

Nathaniel Tools is a small set of REAPER add-ons Jason Zac built for his own multitrack sessions. This page tells you what each one is for, when to reach for it, and how every window works. If a word here needs a dictionary, that is a bug — tell us.

1 · Install (once, two minutes)

  1. Make sure REAPER has ReaPack and ReaImGui (both free). If not: get them from reapack.com and github.com/cfillion/reaimgui, drop the file into REAPER's UserPlugins folder, restart REAPER.
  2. In REAPER: Extensions → ReaPack → Import repositories… and paste https://raw.githubusercontent.com/jasonzacmusic/nathaniel-tools/main/index.xml
  3. Extensions → ReaPack → Browse packages…, right-click Nathaniel Tools → Install All. Install All matters: the apps share one “Shared Libraries” package.
  4. Updates arrive with Extensions → ReaPack → Synchronize packages.

After that everything is in Actions → Show action list — filter on the app's name. To give anything a key: select it → Add… → press the key (or the MIDI pedal).

Teal · look

Palette & Look

Colours and names your tracks from what they are. It reads the track name, its folder and the plugins on it, works out “this is a bass”, “this is a bus”, “this is a reverb return”, and paints it the colour you chose for that family. Your own rules (“anything called harm → purple”) sit on top and win. It can also colour markers and regions the same way, name tracks after their audio file, number them, and re-colour on the fly (LIVE) as you add tracks.

Use it when a session has grown past twenty tracks and you can't find the guitars at a glance. Open it, press APPLY COLOURS. Done.
  1. Apply to — Selection or Whole project. With Selection and nothing selected it tells you, and does nothing.
  2. Families tab — pick a colour per family (Drums, Bass, Keys, Vocals, Harmony, Winds, Bus, FX return …).
  3. My rules tab — your own rules win over families. Import your SWS Auto Color rules if you have them.
  4. Palettes — colour by family, by folder, in order, or “surprise”. Tools — gradients, lighter/darker, match to first selected, children inherit folder colour.
  5. Tracks tab shows now-colour and want-colour for every track; click a swatch to apply just that one.

Green · structure

Folders & Flow

Folders without dragging. Tick tracks → Make folder. Indent, outdent, pull a track out, dissolve a folder, move a whole folder up or down, hide everything except one folder while you work on it, and Repair folder maths for the session where one folder never closed and swallowed everything after it.

Use it when you are building or fixing the shape of a session — the drum kit into one folder, the harmony stack into another, the horns into a third.
  1. Tick the tracks (press one box, drag down to paint many).
  2. Make folder from ticked, or Indent > to push them into the folder above.
  3. On any row: Up / Down moves a whole folder with its children. On a folder row: Dissolve (children stay), Isolate (hide the rest; Show all tracks brings them back — only the ones it hid).
  4. Auto-group by name — neighbours that share a first word (Kick In / Kick Out) become one folder. It shows you the plan and asks first.

Green · structure

Track Settings Transfer

Pro Tools' “Import Session Data”, for REAPER. Open two project tabs, pick FROM and TO; it matches tracks by name and copies FX chains, volume, pan and sends onto the matching tracks — or builds the missing ones. Green rows are exact matches. Amber rows are guesses and stay unticked until you say yes. Nothing is written until you press TRANSFER and confirm. Automation is never copied.

Use it when last week's session has the vocal chain — or the whole drum bus — that this week's session should have.
  1. Open both projects as tabs. From = where the settings are. Tick the To project(s).
  2. Check the rows: exact / guess / new (will be built) / none. Fix a wrong match with the target dropdown on the row.
  3. Untick what you don't want per row (FX, Vol, Pan, Sends). Preview lists what would happen.
  4. TRANSFER — it says exactly what will be replaced and asks. Undo works in each target project.

Amber · delivery

Stem Print & Handoff

Prints stems and puts your session back exactly as it was. Tick tracks and buses, choose Raw (no plugins), Inserts only (the normal dry stem), Fully wet (each stem on its own with its reverb/delay), or Front-end (through the first plugin only). Files print at unity fader and centre pan so the mixer gets clean files. Tick Build a handoff tab and you get a new project tab with the same names, colours and folders, no plugins, and each printed file already on its track — that tab is what you send.

Use it when something leaves your room — to a mixer, a collaborator, another DAW, a student.
  1. Pick how: Raw / Inserts only / Fully wet / Front-end. Leave Unity fader, centre pan on unless the receiver wants your balance printed.
  2. Pick where the files go.
  3. Tick tracks and buses (All buses is the usual answer). Test: first stem only to check one before doing them all.
  4. PRINT → confirm → REAPER renders. Your faders, pans, mutes, plugin bypasses and render settings are put back. One undo step.
  5. Utilities: Uppercase bus names, Plugin-free clone tab (whole session, FX removed, everything else kept).

Amber · delivery

MIDI Batch Export

Many .mid files in one go. Choose the source (selected items / items on selected tracks / regions / every MIDI item), a name pattern such as $num - $name, a folder, see the exact filenames it will write, press EXPORT. It refuses to overwrite by accident. Every file carries the tempo and time signature from where the item sits.

Use it when you want every riff or idea from a session as its own MIDI file — for a student pack, a notation program, or another DAW.

Violet · performance

StageRig early

Live patch switching for the stage. StageRig Build turns a setlist into a project (one folder per patch, instruments loaded, a note tracker in front of each); StageRig shows NOW and NEXT in big letters and switches without cutting off the chord you are still holding — the outgoing patch rings out, then is flushed and muted. GO / PANIC / ALL OFF. Space or Enter = GO. Bind StageRig Next and StageRig Panic to footswitches for hands-free.

Honest status: it works on the studio Mac with real instruments (Pianoteq, Arturia B-3, Dexed, Omnisphere, BBC SO). It has not yet played a paid show. Keep a backup rig until it has.

Every window works the same way

  • Header — the app name, what it does in five words, and Dock (put it in REAPER's docker next to the mixer).
  • Sections in capitals tell you the order: what → where → which tracks → the big button.
  • One big button does the thing. Anything that changes your session in a big way asks first.
  • The status line at the bottom always says what just happened. Log opens the history. Nothing happens silently.
  • Tick columns paint — press on one box and drag down to tick many.
  • Hover anything for a tip in plain words. Every action is one Undo step, named in plain words.

If something is wrong

  • An app says it needs the “Shared Libraries” package → ReaPack → Browse → Nathaniel Tools → Shared Libraries → Install (or Install All on the repository).
  • A window opens but shows a red line at the bottom → the window stays up; read the line and send it to us. Nothing was written to your session.
  • Actions → Nathaniel Tools: Shared Libraries prints what is installed and which version.
