MIDI Batch Export

Seven MIDI files, numbered, in one press. It does not drive REAPER's export action at all — it reads the MIDI and writes the Standard MIDI Files itself, which is the only reason a batch is possible.

Shipping 1.0.0 Nathaniel Tools/scripts/MIDI Batch Export.lua Requires ReaImGui Dockable

The problem

How do I render seven MIDI files with contiguous names?

Jason, mid-session, on a project with seven riffs in it

The answer at the time was: you can't. REAPER's File → Export project MIDI — action 40849 — writes one file, from a time selection, behind a modal dialog. Seven files means making seven time selections, opening the dialog seven times, and typing seven filenames by hand without making a mistake.

That is a five-minute job that happens roughly fifty times a year in a teaching and content pipeline, and every one of those five minutes is spent typing.

The fix

This app never touches 40849. It reads the MIDI directly with MIDI_GetAllEvts and writes the SMF bytes itself.

That turns out to be cleaner than it sounds, because the offsets REAPER hands back are already delta times in the take's own PPQ — they map one-for-one onto SMF delta times. No requantising, no rounding, no drift accumulating across a long take. Tempo and time signature go in as meta events, so the files open at the right speed in Logic, MuseScore, Sibelius or anything else that reads a standard file.

Verified, not assumed

Writing your own file format is the kind of thing that works for the first three files and then quietly produces something a real parser rejects. So the writer was tested against one: a generated file was parsed back with an independent MIDI reader, and chunk lengths, tempo, time signature and every note's pitch and timing survived the round trip exactly.

What it does

  • Export fromSelected items · every item on the selected tracks · regions · every MIDI item in the project.
  • NamingA pattern with $num, $name, $track, $project and $bpm, plus a start number and digit padding.
  • PreviewEvery row shows the exact filename it is going to write before you commit to anything.
  • Collision guardIf two rows would resolve to the same filename it refuses to run, rather than silently overwriting the first with the second.
  • FidelityTempo and time signature written as meta events. Delta times taken straight from the take's PPQ.
  • No modalOne press, one pass, no dialog per file.

In practice that means a pattern like Riff $num - $name with a start number of 1 and two-digit padding turns seven riff items into Riff 01 - Intro.mid through Riff 07 - Outro.mid, and you can see all seven names before anything is written to disk.

Install

In REAPER: Extensions → ReaPack → Import repositories…

https://github.com/jasonzacmusic/nathaniel-tools/raw/main/index.xml

Then Actions → Show action list, filter for Nathaniel Tools, and run Script: Nathaniel Tools MIDI Batch Export. It opens dockable; drag it into a docker once and REAPER remembers.
